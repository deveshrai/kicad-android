Launcher icon sources. `kicad-icon-512.png` is KiCad's `resources/linux/icons/hicolor/scalable/apps/kicad.svg`
rendered at 512 px (legacy `ic_launcher.png` per density). `kicad-icon-adaptive.svg` is the same artwork with
a square full-bleed background, shrunk into the adaptive-icon safe zone (`ic_launcher_foreground.png`).
Rendered with macOS Quick Look (`qlmanage -t -s 512`) and scaled with `sips`.
