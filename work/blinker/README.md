# 555 LED blinker (end-to-end test project)

A CR2032-powered 5 mm LED blinker: an ICM7555 (CMOS 555, runs from 2 V) in astable mode,
R1 1k, R2 47k, C1 10 µF (≈1.5 Hz), C2 10 nF on CV, C3 100 nF decoupling, R3 220 Ω and a red LED,
an on/off slide switch, all through-hole.

Made on a Galaxy Tab (2026-11-06) to test the whole flow in the Android app:
New Project (Android save picker) → schematic (generated by `gen_sch.py`, ERC 0) →
Update PCB from Schematic → placement (`place_pcb.py`) → Freerouting (Specctra export/import) →
zone fill, DRC (0 violations, schematic parity OK) → 3D viewer with STEP models.

`project/` holds the finished files.
